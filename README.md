# 🎮 Space Pong - Projeto em Godot

Este é um projeto que desenvolvi para aprender e reforçar meus conhecimentos na engine **Godot**, utilizando a linguagem **GDScript**.  
Trata-se de um jogo simples estilo *Pong espacial*, com alguns elementos personalizados, como asteroides e sistema de pontuação.

## 🛠️ Tecnologias e Ferramentas

- 🎮 Engine: [Godot Engine 4.x](https://godotengine.org/)
- 💻 Linguagem: GDScript
- 🎨 Sprites e Assets: Criados ou reutilizados para fins educacionais
- 📚 Baseado no curso gratuito do canal [NextIndie Studio](https://www.youtube.com/@NextIndieStudio)

## 📚 Objetivo

O principal objetivo deste projeto foi:

- Praticar conceitos de **nós e cenas** no Godot
- Utilizar **sinais** para comunicação entre objetos
- Aprender a lidar com colisões, movimento e lógica de jogo
- Organizar scripts por entidades (jogador, bola, asteroide, etc.)
- Compreender o fluxo de um jogo simples completo
